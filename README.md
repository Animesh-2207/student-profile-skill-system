# Student Profile and Skill Development Management System

A Spring Boot REST API project using Java 17, Spring Data JPA, Hibernate and MySQL.

## 1. Requirements
- JDK 17 or later
- Maven 3.8+ (or use the Maven wrapper generated by your IDE)
- MySQL Server and MySQL Workbench
- VS Code with Extension Pack for Java and Spring Boot Extension Pack (recommended)

## 2. Create the database
Open MySQL Workbench, connect to your local MySQL server, open `database.sql`, and run at least:

```sql
CREATE DATABASE IF NOT EXISTS student_management;
```

The application creates/updates the `students` and `student_technical_skills` tables automatically on first run.

## 3. Configure your MySQL password
Open `src/main/resources/application.properties` and replace:

```properties
spring.datasource.password=YOUR_MYSQL_PASSWORD
```

with the password for your local MySQL `root` account. Do not share or commit your real password.

## 4. Run in VS Code
1. Open the `student-profile-skill-system` folder in VS Code.
2. Wait for Maven dependencies to download.
3. Open `StudentManagementApplication.java` and click **Run** above `main`, or run from the project terminal:

```bash
mvn spring-boot:run
```

The API runs at `http://localhost:8080`.

## 5. Test APIs
Use Postman, Thunder Client, or curl. Set header `Content-Type: application/json` for JSON requests.

### Create a student — POST `/api/students`
```json
{
  "studentId": "STU101",
  "studentName": "Aarav Sharma",
  "email": "aarav@example.com",
  "courseName": "B.Tech CSIT",
  "programmingScore": 88,
  "mathematicsScore": 92,
  "technicalSkills": ["Java", "Spring Boot", "MySQL"]
}
```

### Other endpoints
| Method | URL | Purpose |
|---|---|---|
| POST | `/api/students` | Register student |
| GET | `/api/students` | Get all students |
| GET | `/api/students/STU101` | Get one student by student ID |
| PUT | `/api/students/STU101` | Update profile/scores/skills (send full JSON body) |
| DELETE | `/api/students/STU101` | Delete student |
| POST | `/api/students/STU101/skills` | Add skill; body: `{"skill":"Python"}` |
| DELETE | `/api/students/STU101/skills?skill=Python` | Remove a skill |
| GET | `/api/students/search/course/B.Tech%20CSIT` | Search by course |
| GET | `/api/students/search/skill/Java` | Search by skill |
| GET | `/api/students/ranking/programming` | Sort by programming score descending |
| GET | `/api/students/ranking/mathematics` | Sort by mathematics score descending |

## 6. Business rules
- Student ID and email must be unique.
- Student ID, name, email and course are mandatory.
- Email must have a valid basic email format.
- Both scores must be between 0 and 100.
- A repeated technical skill is not added twice (case-insensitive check).
- Average = (programming score + mathematics score) / 2.
- Grade: A+ (90+), A (80–89.99), B (70–79.99), C (60–69.99), D (50–59.99), Needs Improvement (below 50).

## 7. Main concepts used
- Encapsulation: private fields with getters and setters.
- Constructor: no-argument and parameterized constructors in `Student`.
- Collections: `List<String>` stores technical skills; service uses stream operations and list manipulation.
- JPA: `@Entity`, `@Id`, `@GeneratedValue`, `@ElementCollection`.
- Repository: Spring Data JPA query methods.
- Service: validation and business rules.
- Controller: REST endpoints using GET, POST, PUT and DELETE.

## Notes
This project intentionally has no frontend; it is a backend REST API. Test it using Postman or Thunder Client. The sample INSERT statements in `database.sql` are optional; if you run them, do not also create the same student IDs through the API.
